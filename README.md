# Civic Issue and Resolution Website

A modern civic tech platform built for Pakistani citizens to report public issues such as garbage collection, electricity outages, water supply problems, gas issues, and road damage.

This project is being developed as an Aptech Vision / Grand Finale exhibition project by a student team.

---

## Project Objective

The goal of this platform is to make civic issue reporting easier and more accessible for citizens across Pakistan.

Users will be able to:

- Report civic problems online
- Use English, Roman Urdu, or Urdu
- Submit complaints related to:
  - Garbage
  - Electricity (Bijli)
  - Water (Paani)
  - Gas
  - Road damage (Sadak)
- Generate structured complaint reports
- Track submitted complaints
